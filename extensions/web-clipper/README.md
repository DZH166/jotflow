# 小董随心录网页归档扩展

## 安装（Chrome 或 Edge）

1. 打开扩展管理页：Chrome 使用 `chrome://extensions`，Edge 使用 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本目录：`E:\Recall\extensions\web-clipper`。

## 使用

在需要保存的网页中点击浏览器工具栏的小董随心录扩展，然后选择“保存离线快照”。归档会保存到浏览器下载目录下的“小董随心录”子目录。

MHTML 文件可直接在 Chrome 或 Edge 中打开。当前阶段尚未自动导入主应用。
