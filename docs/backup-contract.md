# 小董随心录本地备份契约

## 目的

浏览器本地存储会因清理站点数据、重装浏览器或更换设备而丢失。本地备份用于让用户完整带走并恢复自己的记录，不依赖账号或网络服务。

## 备份范围

导出的 `.json` 文件包含：

- 所有记录的文字、标题、来源、时间和置顶状态。
- 已附加图片和普通文件的 data URL 数据。
- IndexedDB 中保存的全部 MHTML 网页快照，以 base64 形式编码。

## 格式

```ts
type RecallBackup = {
  format: 'xiaodong-suixinlu-backup'
  version: 1
  exportedAt: string
  records: RecallRecord[]
  snapshots: Array<{
    id: string
    fileName: string
    mimeType: string
    base64: string
  }>
}
```

`format` 和 `version` 是未来升级格式时的兼容边界。记录元数据与快照二进制保持分离，未来接入云端同步时可以继续沿用记录 API，并替换快照文件的存储位置。

## 导入规则

- 导入前校验文件标识、版本、记录 ID、快照 ID、附件格式、快照大小和快照引用完整性。
- 用户确认后，当前记录和快照将整体替换，不执行不透明的合并。
- IndexedDB 快照替换使用单个事务；若写入记录失败，会恢复之前的快照与记录数据。
- 无效或损坏备份不会改变现有数据。

## 使用建议

- 在清理浏览器数据、更换设备或进行大版本升级前导出一次备份。
- 备份文件含有完整个人内容，应保存在受信任的位置；当前版本不对备份文件加密。
- 导入会替换当前本地数据。需要保留当前内容时，先导出当前备份。
