# 网页离线快照契约

导入快照后，归档文件会保存到当前浏览器的本地 IndexedDB，记录卡片只保存可搜索的元数据。点击“阅读快照”会在应用内打开一个受限阅读器，将归档中已保存的 CSS 和图片资源重建为本地资源后展示静态 HTML；这个动作不会再次下载 `.txt` 或 `.mhtml` 文件。原始归档也会继续保留在本地，并会随“导出备份”一起写入备份文件；导入备份后可以恢复并继续在应用内离线阅读。

## 目标

小董随心录把一个网页保存为可离线打开的静态归档，并保留原始网址、页面标题和保存时间。用户应能在没有网络时查看归档中已包含的文字、样式和图片资源。

## 已实现

- Chrome/Edge 扩展仅对用户当前点击保存的标签页执行采集。
- 使用浏览器的 `pageCapture` API 生成 MHTML 文件。
- 将文件下载到用户本机的 `Downloads/小董随心录/` 目录。
- 文件名包含保存日期和经过清理的页面标题。
- 主应用可导入 `.mhtml` 或 `.mht` 文件，并把归档二进制保存到浏览器 IndexedDB。
- 主应用从 MHTML 头信息读取标题和第一个 `Content-Location` 网址；无法读取时回退到文件名。
- 当前单个快照上限为 20 MB。记录只保存元数据，归档文件与记录分离。
- Edge 可能把早期归档显示为 `.txt`；导入器会根据 MHTML 内容而不是扩展名处理这类历史文件。

## 明确不保证

- 登录态、表单提交、视频播放、实时数据和网页脚本交互。
- 第三方 iframe、受版权或 DRM 保护内容的完整归档。
- 当前阶段把快照自动同步到其他设备。
- 在主应用上下文直接执行归档脚本。阅读页以无脚本、无外网访问的 sandbox iframe 渲染解析后的静态 HTML。
- 保证动态交互、视频和无法从归档中解析的外部资源可用。

## 安全边界

- 扩展只申请 `activeTab`、`pageCapture` 和 `downloads` 权限。
- 不声明任意网站的常驻 host permission。
- 保存由用户点击触发；扩展不在后台自动抓取页面。
- MHTML 归档是外部输入。主应用后续导入时必须把它视为不可信文件，不能直接在拥有应用权限的上下文中执行其中的脚本。

## 后续导入契约

导入主应用时，每份快照将产生一条 `webSnapshot` 记录，至少包含：

```ts
type WebSnapshot = {
  id: string
  originalUrl?: string
  title: string
  capturedAt: string
  archiveFileName: string
  archiveFormat: 'mhtml'
}
```

归档文件本身与记录元数据分开存储，便于未来替换为同步文件存储，而不改变记录 API。
